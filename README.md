# Android Studio Utilities

He desarrollado algunos programillas que pueden ser interesantes para facilitarnos el trabajo. Cada uno de los programas está compuesto por una ventana que se puede ejecutar de manera independiente o puede ser abierto por la ventana principal, que acuta cómo unificadora de todos los proyectos.

## analyzer
Para ayudar a identificar errores de compilación y facilitar la bñusqueda de conflictos en la configuración.

## packer
Para **comprimir** proyectos de Android Studio y poder compartirlos fácilmente eliminando todos los archivos que sobran. El más destacable es el directorio build que ocupa mucho.

## roomgen
Generador de poryectos de Room, necesita pulido, pero facilita mucho la creación de un proyecto ya que estos para funcionar requieren de muna interconexión de muchos archivos.
